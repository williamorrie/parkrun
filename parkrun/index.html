parkrun explorer

Explore UK parkrun events and compare their saved course rankings, on the map or in the searchable list below.

This is a historical snapshot, not a live directory. The original ranking source and update date are not recorded; rankings are approximate positions out of roughly 750 events, not finish times or measured elevation. Check current course details with parkrun before travelling.

Select a marker to see the event name and ranking.

What do the markers mean?

  • Fast / flat: ranks 1–249 (hiker marker).
  • Medium: ranks 250–499 (police marker).
  • Slow / hilly: ranks 500+ (caution marker).
  • No ranking: no saved ranking (information marker).

These are the original explorer's broad labels: a lower number suggests a faster course, but does not guarantee a flat route.

About the optional Google map

The list works without Google Maps. To enable the map, the site owner can set the google-maps-api-key meta tag in parkrun/index.html to a browser key with Maps JavaScript API enabled and billing configured. Restrict the key to the site's HTTP referrers and that API. Keys in static pages are visible to visitors; never use a server-side secret here.

If Google Maps is blocked, offline, or rejects the key, use the event list instead.
